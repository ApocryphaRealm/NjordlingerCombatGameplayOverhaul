Njordlinger Combat Gameplay Overhaul 1.0.0

An overhaul of character progression, classes, gear and soul stones for Skyrim Special Edition: you grow by doing,
your class is a defining choice, an item's tier is where it comes from.

WHAT IS IN THIS BUILD
- Progression: one perk point per level up (a table by level if you want more), no health, magicka or stamina from a
  level up - attributes grow from what you do - and the attribute choice is skipped while those gains are 0. Skill
  caps and skill experience rates are optional controls. Carry weight is left to Adaptive Attributes.
- Classes: choose Warrior, Mage or Thief in the race menu (a Class category) or on the Classes tab. Your class holds
  one skill group (warrior, magic or covert): the skills of the other groups stay at their starting values, their perks
  cannot be taken and do nothing, and their crafting station refuses you (forge, grindstone and workbench for warriors,
  enchanting table for mages, alchemy lab for thieves). Class levels come from your class's own skills; every 10 class
  levels the class evolves - Novice, Apprentice, Adept, Expert, Master, Legendary - and each time you choose one of two
  options for good. A hybrid class opens its second group.
- Quest rewards: the main quest and the Miraak line pay perk points once per character (Quest Rewards tab).
- Item tiers (colours through Inventory Interface Information Injector), unique set keywords and NPC levels by lore
  tier (Keyword Item Distributor, SkyPatcher).

REQUIREMENTS
SKSE64; Address Library for SKSE Plugins; Apocrypha Menu Framework (the settings pages); Keyword Item Distributor;
SkyPatcher; Inventory Interface Information Injector for the tier colours. Not with Character Progression Control -
this mod replaces it (both change the same game code).

SETTINGS
In the Apocrypha Menu Framework: Njordlinger Combat Gameplay Overhaul - Progression, Classes, Quest Rewards.
File: SKSE\Plugins\NjordlingerCombatGameplayOverhaul.ini. Log: Documents\My Games\Skyrim Special Edition\SKSE\
NjordlingerCombatGameplayOverhaul.log.
